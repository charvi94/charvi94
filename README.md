# 📊 Customer Churn Prediction & Business Insights

An end-to-end **Data Analytics + Machine Learning project** analyzing customer churn and converting analytical findings into actionable business recommendations.

### Dataset

**IBM Telco Customer Churn Dataset**

Original dataset:

**7,043 customer records**

Final cleaned dataset:

**7,032 customers**

---

## 📌 Dashboard KPIs

| Metric                  |           Result |
| ----------------------- | ---------------: |
| Total Customers         |        **7,032** |
| Churned Customers       |        **1,869** |
| Churn Rate              |       **26.58%** |
| Average Monthly Charges |        **64.80** |
| Average Tenure          | **32.42 months** |
| Average Total Charges   |        **2,283** |

---

## 🤖 Machine Learning Models

The following classification models were evaluated:

* Logistic Regression
* Random Forest
* Decision Tree

### Model Performance

| Model                   |   Accuracy |  Precision |     Recall |   F1 Score |    ROC-AUC |
| ----------------------- | ---------: | ---------: | ---------: | ---------: | ---------: |
| **Logistic Regression** | **79.39%** | **63.46%** | **52.94%** | **57.73%** | **83.48%** |
| Random Forest           |     78.61% |     62.46% |     48.93% |     54.87% |     82.28% |
| Decision Tree           |     70.65% |     44.88% |     45.72% |     45.30% |     62.69% |

### 🏆 Selected Model

**Logistic Regression**

Selected based on its highest **ROC-AUC of 83.48%**, strong classification performance, and interpretability for business stakeholders.

---

## 🔎 Key Business Insights

* **Month-to-month customers** have the highest churn.
* **Fiber Optic customers** represent a high-risk segment.
* Customers in their **first year** show significantly higher churn.
* **Electronic Check** users are more likely to churn.
* Customers with **higher monthly charges** require greater retention attention.
